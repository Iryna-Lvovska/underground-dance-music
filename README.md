# Underground Dance Music

A webpage exploring the history and sounds of underground British dance music, focusing on UK Garage, Speed Garage and Bassline.

## About the project

The page introduces these influential music styles, explains their distinctive characteristics and explores their connections to British club culture.

It also highlights some of the clubs and venues that helped shape the underground dance music scene, including Niche in Sheffield and influential Garage nights in London.

## Technologies used

- HTML – page structure and content
- CSS – styling and responsive layout
